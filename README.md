# Sistema de Gestion de Solicitudes Academicas

Prototipo de consola para el Trabajo Practico Integrador de Metodologia de Sistemas II.

## Alcance

Registra solicitudes de estudiantes, asigna responsables, cambia estados, filtra por estado y genera un reporte simple. Los datos se guardan en memoria durante la ejecucion. No hay interfaz web ni base de datos.

## Tecnologia

Java 17 o superior, Maven y JUnit. Ejecutar las pruebas con `.\mvnw.cmd test` en Windows o `./mvnw test` en Linux/macOS.

Para ejecutar el ejemplo: `.\mvnw.cmd package` y `java -cp target/classes ar.edu.metodologia.App`.

El archivo `docs/integrante1.md` documenta el diagnostico y el refactoring del integrante 1.
